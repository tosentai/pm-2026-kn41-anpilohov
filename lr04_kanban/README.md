## 1. Definition of Workflow

| Колонка | Картка потрапляє сюди, коли | Картка виходить звідси, коли |
| --- | --- | --- |
| Backlog | Зафіксовано робочий крок проєкту розміром 1–2 дні з ключем `F-0NN` | Зрозумілі критерії завершення задачі й немає нез'ясованих залежностей |
| Ready | Задача розбита до 1–2 днів і є всі вхідні матеріали для старту | У `In progress` звільнився слот нижче WIP-ліміту і роботу фактично розпочато |
| In progress | Виконавець активно працює над артефактом картки саме зараз | Підготовлено чернетку файлу або таблиці, яку можна відкрити й перевірити |
| Review | Артефакт заповнений і відкритий для перевірки (очима або валідатором `validate.py`) | Пройдено самоперевірку / валідатор без помилок і правки внесено |
| Done | Усі вимоги картки виконано, зміни збережені/закомічені та перевірені | — |

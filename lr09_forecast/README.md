## 2. Як рахувалася симуляція

| Поле | Значення |
| --- | --- |
| Інструмент | Python 3 (скрипт Monte Carlo із фіксованим `random.seed(42)`) |
| Прогонів | 10 000 |
| Що тягнеться випадково | `points_done` одного з моїх завершених спринтів (`[8, 11]`) |
| Як рахується дата прогнозу | Для «Весь перший реліз»: кінець спринта 1 (`2026-11-06`) + `(P − 1) × 14` днів; для «Залишок після двох спринтів»: кінець спринта 2 (`2026-11-20`) + `P × 14` днів |

```python
import random

def mc(target, vels, n=10000):
    res = []
    for _ in range(n):
        rem, s = target, 0
        while rem > 0:
            s += 1
            rem -= random.choice(vels)
        res.append(s)
    res.sort()
    return res[int(0.50 * n) - 1], res[int(0.85 * n) - 1]
```

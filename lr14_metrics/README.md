Висновок для команди delta: Найгірше число `delta` — `change_failure_rate = 12%` (12% релізів із помилками, тоді як у `gamma` лише 3%). Порівнювати `delta` коректно лише з `gamma` (обидві працюють на монолітній успадкованій системі), і некоректно з `alpha` чи `beta` (там мікросервіси та повний CI/CD). Першим кроком PM має закрити автотестами критичні бізнес-сценарії моноліту та налаштувати швидкий rollback, щоб знизити кількість збоїв без втрати темпу.
